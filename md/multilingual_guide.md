# Мультиязычная поддержка русского языка в системе поиска

## Обзор

Добавлена поддержка обработки русского и английского языков через единый модуль препроцессинга `utils/text_processor.py`. Система теперь может работать с:

1. **Английскими текстами** (как и раньше)
2. **Русскими текстами** (новая функциональность)
3. **Смешанными текстами** (сочетание английского и русского)

## Архитектура решения

### Ключевые изменения:

1. **Создан общий модуль `utils/text_processor.py`**, который предоставляет:
   - Единую точку препроцессинга для всего проекта
   - Поддержку мультиязычности (автоматическое определение языка слов)
   - Ленивую инициализацию для оптимизации производительности
   - API для обратной совместимости

2. **Обновлены все модули**, использующие препроцессинг текста:
   - `preprocess_corpus.py` - для создания индекса
   - `searches/lecsika_search.py` - для лексического поиска (BM25)
   - `searches/tfidf_search.py` - для TF-IDF поиска
   - `searches/hnsw_search.py` - для HNSW поиска
   - `vectoryzing/query_vectorizer.py` - для векторизации запросов
   - `benchmarks/benchmark_hnsw.py` - для бенчмарков
   - `neural_train_process_data/feature_extractor.py` - для извлечения признаков LTR

3. **Добавлены зависимости**:
   - `pymorphy3[fast]` - для лемматизации русского текста
   - `snowballstemmer` - для стемминга русского текста

## Использование нового функционала

### Для разработчиков:

```python
# Импорт общего процессора
from utils.text_processor import preprocess_text, preprocess_text_to_string, processor, tokenize

# 1. Мультиязычный режим (по умолчанию) - автоматически определяет язык каждого слова
tokens = preprocess_text("Neural networks и нейронные сети", language='multilingual')
# Результат: ['neural', 'network', 'нейронный', 'сеть']

# 2. Только английский
tokens_en = preprocess_text("Neural networks и нейронные сети", language='en')
# Результат: ['neural', 'network'] (русские слова игнорируются)

# 3. Только русский
tokens_ru = preprocess_text("Neural networks и нейронные сети", language='ru')
# Результат: ['нейронный', 'сеть'] (английские слова игнорируются)

# 4. Автоматическое определение языка
tokens_auto = preprocess_text("Смешанный текст mixed text", language='auto')

# 5. Для обратной совместимости (старый API)
tokens_compat = tokenize("neural networks")  # Работает как раньше
```

### Для пользователей системы поиска:

1. **Работа с русскими запросами**:

   ```bash

   python main.py lexical search
   # Введите запрос: нейронные сети
   
   python main.py hybrid search
   # Введите запрос: градиентный бустинг алгоритм
   ```

2. **Работа с корпусом на русском языке**:
   - Система автоматически обрабатывает русские документы в корпусе
   - Индексы строятся с учетом русских слов
   - Поиск работает по русским ключевым словам

3. **Смешанные запросы**:
   - Можно комбинировать английские и русские слова в одном запросе
   - Пример: "neural networks архитектура"

## Конфигурация

### Языковые режимы:

- `'multilingual'` (по умолчанию): обрабатывает слова обоих языков
- `'en'`: только английские слова
- `'ru'`: только русские слова  
- `'auto'`: автоматическое определение для каждого слова

### Настройки обработки:

```python
# Расширенные настройки
tokens = preprocess_text(
    text="Текст для обработки",
    language='multilingual',
    use_stemming=True,           # Применять стемминг/лемматизацию
    remove_stopwords=True,       # Удалять стоп-слова
    min_length=2                 # Минимальная длина слова
)
```

## Алгоритмы обработки

### Для английского текста:
1. Токенизация (NLTK word_tokenize)
2. Приведение к нижнему регистру
3. Удаление стоп-слов (NLTK english stopwords)
4. Стемминг (PorterStemmer)

### Для русского текста:
1. Токенизация (NLTK word_tokenize)
2. Приведение к нижнему регистру
3. Удаление стоп-слов (NLTK russian stopwords)
4. **Лемматизация (pymorphy3)** - более точная, чем стемминг

## Производительность

### Ленивая инициализация:
- Ресурсы NLTK загружаются только при первом использовании
- Морфологический анализатор pymorphy3 инициализируется один раз
- Нет дополнительных накладных расходов при повторных вызовах

### Оптимизация:
```python
# Создаем один экземпляр процессора на все время работы приложения
from utils.text_processor import processor

# Ленивая инициализация
tokens1 = processor.preprocess_text(text1)  # Первый вызов инициализирует ресурсы
tokens2 = processor.preprocess_text(text2)  # Второй вызов использует уже загруженные ресурсы
```

## Решение проблем

### Проблема: ошибка импорта pymorphy3
**Решение:**
```bash
pip install pymorphy3[fast]
```

### Проблема: медленная обработка при первом запуске
**Решение:**
- Это нормально - ресурсы загружаются один раз
- На следующих запусках будет быстрее

### Проблема: русские слова не находятся в поиске
**Решение:**
- Убедитесь, что корпус переиндексирован с новым процессором
- Запустите `python main.py init` для полной переиндексации

## Заключение

Добавление поддержки русского языка делает систему поиска более гибкой и полезной для русскоязычных пользователей. Реализация через единый модуль препроцессинга обеспечивает:

1. **Централизованное управление** - все настройки в одном месте
2. **Поддержку мультиязычности** - автоматическая обработка разных языков
3. **Обратную совместимость** - существующий код продолжает работать
4. **Производительность** - оптимизированная обработка больших объемов текста
5. **Расширяемость** - легко добавить поддержку новых языков

Система готова к использованию с русскоязычными корпусами и запросами, сохраняя при этом все существующие функции работы с английским языком.
